# Descripción

Script interactivo en Python diseñado para analizar cadenas de texto ingresadas por el usuario y determinar si están compuestas únicamente por caracteres numéricos.

## Conceptos aplicados

* **Interacción Dinámica:** Uso de input() para capturar datos en tiempo real.

* **Control de Flujo:** Implementación del bucle for y la sentencia break para optimizar la búsqueda y detener la iteración al encontrar la primera coincidencia.

* **Evaluación de Cadenas:** Uso del método nativo .isdigit() para la validación de caracteres numéricos.

* **Salida Formateada:** Implementación de f-strings para desplegar mensajes dinámicos según la validación lógica.
